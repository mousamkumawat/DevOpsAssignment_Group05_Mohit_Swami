## About the Project

The **Build Phase** is the stage of the DevOps lifecycle where source code is transformed into a usable software package or **build artifact**.

This phase involves compiling or processing the source code, managing required dependencies, generating necessary files, and packaging the application into a form that can be used in the subsequent stages of the software lifecycle.

Our project explains the Build Phase through **real-world examples, visual workflows, tools, and practical demonstrations**.

---

## DevOps Lifecycle

```text
Plan → Code → 🔨 Build → Test → Release → Deploy → Operate → Monitor
```

## Build Phase at a Glance

```text
Source Code
     ↓
Dependencies
     ↓
Compilation / Processing
     ↓
Packaging
     ↓
📦 Build Artifact
```

The main goal is to convert the application's source code into a **structured and usable output**.

## Build Tools

Some commonly used tools associated with the Build phase are:

* **Maven** – Java build and dependency management
* **Gradle** – Build automation for Java/Android projects
* **npm** – JavaScript/Node.js package and build management
* **MSBuild** – Building .NET applications
* **Docker** – Building application container images
